## Çalıştırmak için

Node.js ve Python 3 gerekiyor.

```bash
git clone https://github.com/oktayelb/teker.git
cd teker
npm install
npm run dev
```

Sonra tarayıcıda [http://localhost:8000](http://localhost:8000) adresini aç.

Sürüş: `W A S D` ya da yön tuşları · `Space` el freni · `Esc` menü.
